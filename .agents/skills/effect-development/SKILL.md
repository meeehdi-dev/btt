Before using an Effect API, search the matching version's official Effect documentation and examples for that API and pattern. Inspect nearby source/tests for conventions. The task is ready when every material Effect API has matching official guidance or a documented absence of guidance.

This project uses the pinned Effect v4 RC; confirm v4 API names against installed package declarations and official v4 documentation rather than copying v3 examples.
